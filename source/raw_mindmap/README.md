# Raw Mindmap 输入目录

把树形结构的文本文件放在这里，部署时会自动转换为 markmap 思维导图。

## 支持的格式

使用树形字符（`├─`、`└─`、`│`）的文本文件：

```
├─ 【系统组成层・整体包含关系】
│  └─ DBS 数据库系统（最大范畴）
│     ├─ DB 数据库
│     │  └─ 数据库对象
│     │     ├─ 表
│     │     └─ 视图
│     └─ DBMS 数据库管理系统
```

## 转换结果

转换后的 markmap 文件会输出到 `source/mindmap/source/`，文件名不变（仅改扩展名为 `.md`）。
