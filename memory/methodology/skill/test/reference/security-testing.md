# 安全测试

按安全清单与扫描工具检查系统漏洞：认证授权、注入、XSS、越权、敏感信息泄露等，覆盖 OWASP Top 10 核心风险。

## 执行指令

1. **资产盘点** — 列出接口、数据、权限边界、外部依赖
2. **威胁建模** — 识别高风险入口（登录、上传、支付、导出）
3. **按清单检测** — SQL 注入 / XSS / CSRF / 越权 / 弱口令 / 敏感信息
4. **工具扫描** — 依赖漏洞扫描、SAST 静态分析、OWASP ZAP 探测
5. **验证利用路径** — 确认漏洞可被真实利用（非纸面风险）
6. **输出报告** — 漏洞清单 + 等级 + 复现 + 修复建议

## 使用示例

### 用户输入
"检查这个登录接口是否存在 SQL 注入与越权"

### 预期输出
```
1. SQL 注入：对 username 传 ' OR '1'='1，响应是否异常 → 参数化查询已防护 ✅
2. 越权：用普通账号 A 的 token 访问 B 的数据 → 返回 403 ✅ 已鉴权
3. 敏感信息：登录响应与日志中是否明文密码/密钥 → 需修复（泄露项列明）
```

## 故障处理

| 场景 | 应对 |
|------|------|
| 扫描工具误报 | 手动验证利用路径，区分真实风险与配置噪音 |
| 高危漏洞无法立即修复 | 给出缓解措施 + 优先级排期，记录跟踪 |
| 授权边界不清 | 与业务确认资源归属，再判定越权 |

## 做什么不做什么

### ✅ 做什么
- 检查认证授权（越权、token 校验、会话管理）
- 检查注入、XSS、CSRF、文件上传安全
- 检查敏感信息泄露（日志、响应、前端源码）
- 扫描依赖漏洞与已知 CVE

### ❌ 不做什么
- 未获授权对生产系统实施攻击性测试
- 只测功能可用性，忽略安全风险
- 把低危项当不存在（合规性同样重要）
- 验证后不记录复现步骤与修复建议
