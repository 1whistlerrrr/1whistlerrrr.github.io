# Bug 修复自检清单
测试通过后（步骤 7）逐项核验，全部通过后方可输出交付物。

## 测试验证（步骤 7）
- [ ] 已按复杂度等级完成对应深度的测试（🟢快速 / 🟡标准 / 🔴全面）
- [ ] 原复现步骤确认问题已消失（正向验证）
- [ ] 修复代码的所有调用方核心路径功能正常（回归验证）
- [ ] 边界条件已验证（空值/极值/并发等，视复杂度而定）
- [ ] 如涉及数据变更，数据一致性已确认

## 修复有效性
- [ ] 修复逻辑覆盖了所有已知触发条件
- [ ] 没有引入新的问题（回归风险）
- [ ] 已梳理所有调用方，确认修复不破坏已有功能
- [ ] 共享数据结构/公共方法的修改已评估全部影响范围

## 代码规范
- [ ] 只改了必要的代码，无多余修改
- [ ] 代码风格与周围一致
- [ ] 无安全隐患（日志脱敏、异常处理等）
- [ ] 修复点已添加规范注释

## 同步检查
- [ ] 相同代码在其他模块是否存在同样问题（是否需要同步修复）
- [ ] 是否需要补充/更新自动化测试用例
- [ ] 是否需要更新相关文档
